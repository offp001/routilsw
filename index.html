A TOOLBOX, NOT A PLATFORM

One utility.
Plenty of uses.

RoUtils brings a range of Roblox utilities into one place. Inspect cached assets, organize FFlag configs, preview supported files, check public server details and keep useful shortcuts close by.

Feature availability depends on your platform, client version and supported file types. Read the docs before changing client files.

DOC 01

Install the release

For most Windows users, the simplest route is to download the current executable from the latest GitHub release. If no downloadable asset is attached to a release, the button will open the release page instead.

Open latest release ↗
DOC 02

Build from source on Windows

The repository's contributor guide specifies Python 3.12 or newer for the Windows source build.

  1. Install Python and enable Add Python to PATH.
  2. Extract the RoUtils repository.
  3. Run install_requirements.bat.
  4. Run compile.bat.
  5. Launch dist\RoUtils.exe.

Manual build: pip install -r requirements.txt, then run the PyInstaller command described in CONTRIBUTING.md.

DOC 03

Build from source on Linux

The repository includes a separate routils_src_linux folder. Follow its included shell scripts and platform-specific contributor instructions.

  1. Install Python, pip, venv and Tk support using your distribution's package manager.
  2. Open a terminal in routils_src_linux.
  3. Make the shell scripts executable if needed.
  4. Run ./install.sh then ./compile.sh.
  5. Launch the resulting executable from dist.

03

DOC 05

Notes & care

RoUtils works with local client data and configurable files. Features can behave differently as Roblox changes its client format. Review what a preset or plugin changes before applying it, and only import plugins you trust.

RoUtils AI is optional and requires a Gemini API key entered in the application settings. Keep API keys private and never commit them to a public repository.
